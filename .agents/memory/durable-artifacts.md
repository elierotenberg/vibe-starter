# Durable artifacts

Keep source-controlled content limited to material intended to outlive the current task. Plans, scratch notes, prompt transcripts, temporary reports, and draft messages remain in ignored `*.local.*` files unless the user deliberately promotes them to project documentation.

Record consequential decisions in the relevant durable documentation with their rationale, constraints, and rejected alternatives. Do not mention confidential reference projects, private paths, chats, or agent provenance in committed code, comments, documentation, commit messages, issues, or pull requests; describe an adopted pattern on its own merits.
